# MyFirstMCP

My first Model Context Protocol (MCP) project built with Python.

## Goal

The goal of this project is to learn how to:

- build an MCP server in Python
- create and expose MCP tools
- connect an MCP client to the server
- use an online LLM with tool calling
- keep the MCP server independent from the selected LLM provider

## Planned architecture

- Python
- Model Context Protocol (MCP)
- Local MCP server
- stdio transport
- Groq cloud LLM
- Git and GitHub
